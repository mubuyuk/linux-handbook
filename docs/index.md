# Linux Handbook

Ett personligt uppslagsverk för Linux – en samling kunskap, kommandon och praktiska exempel som jag använder och lär mig längs vägen.

## Ämnen

- Linux-grunder och terminalen
- Kommandon och verktyg
- Systemadministration
- Nätverk
- Docker och containers
- Felsökning

## Hur handboken används

Använd **sökfältet** högst upp för att snabbt hitta ett kommando eller begrepp,
eller bläddra i menyn.

Varje artikel försöker besvara fyra frågor:

1. **Vad är det?**
2. **Hur fungerar det?**
3. **Hur använder jag det?**
4. **Att tänka på**

!!! info "Under uppbyggnad"
    Handboken byggs ut successivt i takt med att jag lär mig nya saker och
    stöter på verkliga behov. Den gör inte anspråk på att täcka hela Linux.
